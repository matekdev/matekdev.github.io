Goblins Fortune is a [Spelunky](https://store.steampowered.com/app/239350/Spelunky/)-inspired platformer with procedurally generated levels. It was a multi-week project to test how well s&box, a 3D engine, could handle a 2D game. I worked on systems, AI, pathfinding, gameplay, and UI.
