TTT is a recreation of the classic [Garry's Mod](https://store.steampowered.com/app/4000/Garrys_Mod/) game mode in s&box. It was my first big multiplayer project in the engine. I led development, with help from another programmer and the community.

I worked on core systems, gameplay, and networking. The game reached thousands of players, and other people later used the open source code to build their own versions.

<Img src="ex2.webp"  />

I posted devlogs on YouTube, which got tens of thousands of views. Development eventually stopped because s&box was changing so fast that every engine update broke major parts of the game.
